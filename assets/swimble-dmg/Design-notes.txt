Files

Swimble-DMG-Background@2x.png: 1600 × 1000 pixels.
Swimble-DMG-Background.tiff: both resolutions in one file (72 / 144 dpi),

Matching editable sources: Swimble-DMG-Background.tsrct and

Installer layout (coordinates relative to the content area, in points)

Use icon view with labels below icons. Hide the toolbar and sidebar.

folder icons or their file labels into the background image.

This deliverable is a background image, not a packaged disk image.

Render from the repository root:
