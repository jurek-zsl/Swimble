Swimble macOS app icon

Native source: ../../MacClient/Resources/Swimble.icon/
Portable copy: Swimble.icon.zip (unzip before opening in Icon Composer)
Fallback: Swimble.icns (generated by Apple's asset compiler)
Previews: Swimble-macOS-Default.png, Swimble-macOS-Dark.png,
          Swimble-macOS-Tinted.png (1024 × 1024, macOS 26 rendering)

The native .icon document has a solid petrol background and separate headset
and swift SVG layers. macOS applies its own mask, materials, and appearance
variants. The source artwork has no baked gradients, shadows, or corner mask.
SVG strokes are expanded into closed filled paths for correct glass rendering.

MacClient/project.yml includes Resources/Swimble.icon in the app target and
sets ASSETCATALOG_COMPILER_APPICON_NAME to Swimble. Xcode compiles Assets.car,
Swimble.icns, CFBundleIconName, and CFBundleIconFile into the .app.
Use this build configuration for Liquid Glass and appearance adaptation;
a standalone .icns is the flattened fallback, not the layered source.

Rebuild from the repository root:
  (cd MacClient && xcodegen generate)
  xcodebuild -project MacClient/Swimble.xcodeproj -scheme Swimble -destination 'platform=macOS' build

Verified with Xcode 27.0, targeting macOS 26.0. The application build passed.
The existing Rust archive emitted newer-deployment-target linker warnings;
no Rust or Swift implementation was changed for this icon integration.
